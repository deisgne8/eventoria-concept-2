# Eventoria Concept 2

Responsive Eventoria concept website with animated Expertise, Work, Process, and project sections.

## Preview locally

Run `python3 -m http.server 8127` from this directory, then open http://localhost:8127.

No build step is required. The site can be served from any static host.

## Photography

Unsplash sources and photographer credits are listed in `photo-credits.html` and `assets/unsplash/credits.json`.
